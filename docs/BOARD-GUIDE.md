# Floating Whiteboard: what else can I do?

A guide for teaching on a classroom panel or a laptop.
Written for version **1.7.0-beta.4**, checked on 2 November 2026.

This guide starts after the everyday drawing tools.
It leaves out the basics of writing, highlighting, erasing, colours,
typing, undo and adding a page.

**More** means the More button on the bottom toolbar.
The little tab on either edge also brings the menu to that side.
Drag the toolbar's grip to put it on the left, in the centre or on the right.
Menus can scroll: look below the first row of tiles.

## About the checks in this guide

**Checked in app** means the feature was exercised in the Windows Electron app
with a temporary lesson and test profile.
Some checks use simulated pen and touch events.
They do not prove how a particular classroom panel feels.

**Opened in app** means its screen or control was opened and inspected.
Its full result was not necessarily checked.

**Not checked** means the instructions come from the current app's workings,
but that particular result was not tried here.
Limits and scientific assumptions are explained even when a control was checked.

## Keep a lesson, find it again and carry it elsewhere

### Start a named lesson

**Find it:** More › New lesson.

This makes a separate lesson file, with a name and an optional subject or class.

1. Give the lesson a useful name, such as “Class 8 · Friction”.
2. Add a subject or class if you want lessons filed together.
3. Choose Notebook for separate pages, or Canvas for one large working space.
4. Tap Start the lesson.

An empty name uses the date and time.
The file is created in Documents › Floating Whiteboard › Lessons.
It saves itself as you teach.
The subject here is a filing label; it does not restrict the teaching tools.

**Check:** Checked in app.

### Find, rename, copy or remove a lesson

**Find it:** More › My lessons.

1. Search by lesson name or subject.
2. Tap the lesson's picture to open it.
3. Use its three-dot button for Rename, Subject, Make a copy,
   Show in folder or Delete.
4. Use Open a file… for a lesson saved elsewhere on the PC or a USB drive.

Lessons are grouped by subject, with recently used groups first.
The current lesson is marked Open now and has no Delete button.
A lesson opened elsewhere stays in that location; opening it does not
automatically move it into the Lessons folder.
Rename also renames the lesson's file in its current folder.

**Check:** Checked in app. Windows Explorer's resulting folder window was not checked.

### Save another editable copy

**Find it:** More › Save a copy….

1. Choose a folder and file name.
2. Save the whiteboard lesson file.
3. Check the lesson's save message before closing or removing a USB drive.

Use this for another editable copy.
Use Export for a picture or PDF that people can view without the board app.
After Save a copy, the chosen file becomes the lesson's current save file.
Ctrl+S asks for a save now.
A Not saved message means the save needs attention; tap it to retry.

**Check:** Saving and reopening copies checked in app.

### Recover an earlier save

**Find it:** More › Earlier saves.

1. Open the list and compare the dates and object counts.
2. Tap the save you want to restore.
3. Check the recovered board. Undo can restore the board you just replaced.

The app keeps five previous board saves, making a snapshot at most once a minute.
A snapshot appears when an existing save is replaced.
This is a short recovery history, not an archive of every lesson version.
An empty list can be normal on a new profile.

**Check:** Recovery panel opened in app. Restoring a real historical save was not checked.

## Arrange the space for the lesson

### Notebook, canvas and frames

**Find it:** More › Turn into canvas / Turn into notebook,
or More › Settings › This board.

A Notebook is a sequence of pages that fit the teaching area.
A Canvas is a large board you can move around and zoom into.
Frames mark views of the canvas so you can step through it like slides.

1. Choose the kind of board you need.
2. In a Notebook, tap Pages to see the page pictures.
3. On a Canvas, add a frame, then use Frames to see and visit the saved views.
4. Use Frame what's on screen to mark the current canvas view,
   or New frame after the last for another working area.

Converting carries the drawings across.
Notebook pages become canvas frames.
Converting a canvas back to a notebook makes one page per frame,
keeping its paper, picture, colour and title.
An object's centre decides which frame's page receives it.
Work outside all frames goes onto extra pages so it is kept too.
Removing a canvas frame removes its boundary, **not the drawing inside it**.

On a Canvas, use Move board from the Select choices,
Space+drag, two fingers, or the zoom controls.
Ctrl+wheel zooms; Ctrl+0 resets the zoom; Ctrl+1 fits the content.
A Notebook keeps its page at a fixed fit size rather than offering free zoom.

**Check:** Conversion, canvas navigation and frames checked in app.

### Organise pages and sections

**Find it:** Pages or Frames on the bottom toolbar.

1. Tap a page picture to visit it.
2. Tap its title to rename it.
3. Use the small left and right buttons to move it earlier or later.
4. On a Notebook page, use Duplicate page to reuse the whole page.
5. Use Start a section here to add a heading for a run of pages or frames.

Tap a section heading to rename it.
Removing the heading leaves the pages in place.
Deleting a Notebook page removes its contents; deleting a frame leaves canvas art.
The sorter offers an Undo message for its recent structural change.

**Check:** Page and section actions checked in app.

### Make a page longer

**Find it:** The downward-space button on the right edge of a Notebook.

1. Tap More space below.
2. Scroll down to continue the same page.
3. Drag the little page map to move through a long page quickly.
4. Remove empty space at the bottom when its button appears.

A page can be up to eight screens long.
The shrink button only removes empty space.
Two-finger horizontal swipes can turn Notebook pages;
vertical movement scrolls a long page.

**Check:** Long pages and page navigation checked in app with simulated input.
Real multi-touch panel gestures were not checked.

### Choose the board surface and paper

**Find it:** More › Background. The same controls are in Settings.

1. Pick a board surface, or choose your own background colour.
2. Choose Smooth, Chalk, Slate or Paper texture.
3. Choose the paper pattern or lesson layout.
4. Adjust its spacing, strength and line colour where offered.

The surfaces are Whiteboard, Chalkboard, Green board, Slate,
Navy board, Paper, Brown paper and Cool grey.
Choosing your own colour keeps the current texture.

Paper choices:

| What you want | Choices |
| --- | --- |
| Writing practice | Plain, Ruled, Four-line, Hindi lines |
| Maths work | Squares, Graph paper, Dots, Isometric dots, Isometric grid, Semi-log, Log-log, Polar |
| Music or lesson structure | Music, Two columns, Three columns, Worked example, Exit ticket |
| Sport | Football, Cricket, Basketball, Kabaddi |

Ruled paper supplies ordinary writing lines; Four-line and Hindi lines
guide letter height and baselines.
Squares and Dots give a simple construction guide.
Graph paper has smaller divisions; the two isometric choices guide 3D sketches.
Semi-log has logarithmic spacing vertically; Log-log has it both ways.
Polar has rings and angle divisions. Music supplies five-line staves.
Two columns suits comparisons; Three columns suits predict, observe and explain.
Worked example leaves a top question area, left working area and right notes area.
Exit ticket supplies three numbered answer boxes.
Each playing field supplies that sport's markings for tactics or discussion.
Fitted layouts and playing fields repeat for each screen of a long page.

There are three **separate** scope choices:

- Board colour and texture normally apply to the whole lesson.
  Turn on Only this page / frame to change just the current one.
- Paper normally applies to the current page or frame.
  Turn on its All pages / frames button to change all of them.
- The picture behind the writing has its own All pages / frames button.

Whole-lesson surface choices and paper choices also become defaults
for new lessons. A background picture does not.
Spacing presets are Small, Medium and Large, with finer plus/minus steps.
Spacing is offered for patterns, not fitted layouts or playing fields.
Strength is Faint, Normal or Strong.
Usual restores the paper's normal line colour.
Margins and writing baselines keep their red marks.
Restore the paper as designed resets its tuning.
Graph markings are teaching guides, not calibrated physical millimetres.

**Check:** Paper patterns, scope, tuning and saved backgrounds checked in app.

### Put a worksheet behind the writing

**Find it:** More › Background › Picture behind the writing.

1. Choose picture…, or select an existing picture and use Use selected picture.
2. Choose Whole picture to keep all of it, or Fill the page to fill the area.
3. Pick its position and strength.
4. For a long page, choose First screen, Every screen or Whole page.
5. Crop, replace or remove it from this same panel.

This picture is part of the background.
Clearing or erasing writing leaves it in place.
The All pages choice applies to existing pages; it is not a picture default
for future lessons.
You can import a PDF, select its page picture and use it as the background.
Do that once on a trial page to see the result before converting a full lesson.

**Check:** Background-picture placement, crop and saving checked in app.

## Take hold of objects and reuse work

### Select, lasso, move and resize

**Find it:** Select on the toolbar. Tap it again for Select, Lasso
and, on a Canvas, Move board.

1. Choose Select and tap an object, or drag a box around several objects.
2. Choose Lasso to draw around the things you want.
3. Drag the selection to move it.
4. Drag a corner to resize it, or its rotation handle to turn it.

Shift+resize keeps proportions; Shift+rotate snaps to 15-degree steps.
Arrow keys nudge; Shift+arrow moves in larger steps.
Grouped objects are picked together. Ungroup when you need their pieces.
Locked objects can still be selected so you can unlock them.

**Check:** Selection, lasso, grouping, resizing and rotation checked in app.

### Use the selected object's action bar

**Find it:** Beside a selected object. Some actions appear only for certain objects.

1. Select the object.
2. Choose the named action from its bar.
3. Open More on this bar for the less common actions.

| Action | What to do and what to know |
| --- | --- |
| Style | Change compatible objects' fill, border, line thickness, opacity and label style. Shapes can have solid, dashed or dotted borders; rectangles can have rounded corners. Lines and arrows offer straight or elbow paths. A mixed selection only changes the kinds that support that setting. |
| Edit / Type | Edit an existing note, shape label or table cell. Bigger, Smaller and Bold appear for a single editable label. Shape labels stay with their shape. |
| To text / To maths | Read selected handwriting with a connected AI model. Only ordinary, non-highlighter handwriting qualifies. Review and correct the answer before Replace the writing. See Assistant below. |
| Set | Open an apparatus part's settings. Dragging a settings slider previews its value; releasing commits the change. |
| Play | Play an inserted audio or video clip. |
| Crop | Crop a normal picture. Drag the crop area or its corners, then apply it. An equation picture has its own Edit action instead. |
| Branch | Add a connected shape to build a mind map or flow chart. |
| Edit graph / equation / scale | Reopen the special editor. The result remains editable through that editor. |
| Group / Ungroup | Keep several objects together, or separate their pieces. The button appears when several objects are selected. |
| Copy | Make another copy immediately. This bar's Copy means Duplicate selection; Ctrl+C and Ctrl+V use the clipboard. |
| Mirror / Flip | Reflect left to right or turn upside down. |
| Shelf | Save the selected work for another lesson. |
| Hide | Make the selected work wait for a lesson step. See Prepare reveals below. |
| Lock / Unlock | Protect an object from moving, ordinary style changes, erasing and deletion. Unlock to edit it again. Live apparatus controls are also blocked when locked. |
| Delete | Remove unlocked objects in the selection. Locked ones stay. |
| More › Add a link | Give one unlocked object a web address. Save it; Open link then opens it in the browser. A normal website name is accepted. |
| More › Bring to front / Send to back | Change which overlapping object is visible on top. |
| More › Rotate 90° | Make an exact quarter-turn. |
| More › Fit selection in view | Bring selected work into view on the canvas. |
| More › Unlock all objects | Remove locks from the current board's objects. |

Locked artwork keeps its style in a mixed selection.
Duplicate copies are independent and unlocked.
The bar can change while you select different kinds of objects.

**Check:** Object actions checked in app. Opening a real external website was not checked.
AI reading was checked with a test model, not for recognition accuracy.

### Shapes, connectors and mind maps

**Find it:** Shapes on the toolbar, or More › Mind map.

1. For a diagram, choose Line, Arrow, Rectangle, Ellipse, Diamond or Triangle.
2. Drag to place it. Hold Shift for constrained shapes or directions.
3. Select a closed shape to add its label or change its style.
4. For a mind map, start with More › Mind map, select a node and tap Branch.
5. Move a connected node: its attached lines follow it.

Connectors attach to objects when their ends land on them.
The Style panel can switch them between straight and elbow paths.
A rough line, circle, rectangle or triangle can also become a neat shape:
draw it, then hold still at its end for about 0.6 seconds before lifting.
Starting with a stationary press opens the radial menu instead.

**Check:** Shapes, branches and attached connectors checked in app.
Shape recognition was checked with simulated strokes.

### Sticky notes

**Find it:** More › Sticky note.

1. Choose Sticky note and place one on the board.
2. Write the idea in it and finish editing.
3. Select it to change its fill, size, label style or list style.
4. Duplicate or save it to My shelf when it will be useful again.

It is an editable board object, not a reminder outside the lesson.
It can be grouped, locked or hidden like other objects.

**Check:** Checked in app.

### Tables

**Find it:** More › Table.

1. Choose the number of rows and columns and whether to use a heading row.
2. Tap Put on the board.
3. Select the table and tap Type, or open a cell for editing.
4. Drag internal boundaries to adjust row heights and column widths.
5. Use the selection bar's More for Add row, Add column,
   Remove row, Remove column and Heading row.

Enter makes a new line **inside** a cell.
Tab moves to the next cell; Shift+Tab moves back.
Escape or a tap elsewhere finishes and saves the cell.
Each completed cell is one undo step.
Hindi input through the Windows keyboard is supported by the text field.
Tables can have up to 20 rows and 12 columns.

**Check:** Checked in app, including cell navigation and saved tables.
Typing with a real Hindi keyboard setup was not checked.

### Ready lesson templates

**Find it:** More › Templates.

1. Pick Venn diagram, Three circles, KWL chart, Two columns,
   Timeline, Steps, Cycle or Worksheet.
2. Move the result into place.
3. Select its pieces to rename, resize or remove them.
4. Ungroup grouped pieces when you need to move them separately.

Templates are made from ordinary editable objects.
They do not change the page's background paper.
For a reusable version with your own wording, save it to My shelf.

**Check:** All eight templates checked in app.

### My shelf

**Find it:** More › My shelf, or Shelf on a selection's action bar.

1. Select a diagram and tap Shelf; give it a name and optional subject.
2. Or open My shelf and choose Save this page / frame / what's on screen.
3. In another lesson, search the shelf and tap the saved picture to use it.
4. Use the item's three-dot button to rename it, change its subject or delete it.

A saved diagram inserts a fresh copy; changing it does not rewrite the shelf item.
A Whole page item brings its page settings as well as its objects.
Save shelf to a file… carries the shelf to another classroom PC.
Add from a file… imports a shelf file; already-present items can be skipped.

**Check:** Saving, inserting and transporting shelf items checked in app.

## Bring in material from other places

### Pictures and diagrams

**Find it:** More › Picture, or Subjects › Picture / diagram.

1. Choose one or more image files.
2. Place and resize them with Select.
3. Use Crop if you only want part of the picture.
4. Lock a worksheet picture before asking students to write over it.

You can also drop supported files onto the board.
Pasting a picture from the clipboard is another way to bring in a screenshot.
An ordinary picture remains an object until you use Background ›
Use selected picture.

**Check:** Image import, drop/paste and crop checked in app.

### PDF / worksheet

**Find it:** More › PDF / worksheet.

1. Choose the PDF.
2. Wait for the page-import message to finish.
3. Use Pages or Frames to visit the imported sheets.
4. Write over the sheet; unlock its picture only if you want to move or crop it.

Each PDF page becomes a **locked picture**, not editable PDF text.
The first sheet reuses an empty current page; later sheets are added after it.
Portrait worksheets can make a long page.
On a Canvas, imported pages become frames.
Only the first 300 pages are imported.
Password-protected PDFs may be refused.

**Check:** PDF import checked in app. Password-protected input was not checked.

### PowerPoint and old OpenBoard lessons

**Find it:** More › PowerPoint. This picker also accepts OpenBoard lesson files.

1. Choose a PowerPoint presentation or an OpenBoard lesson.
2. Wait for the import to finish and read its message.
3. Inspect the resulting pages before using them in class.

When Microsoft PowerPoint is available, the app first tries to turn slides
into PDF so they keep their appearance.
Without that conversion, a modern PowerPoint file is read as editable text
and pictures; unsupported pieces can be skipped.
For exact appearance, save a PDF in PowerPoint and import that PDF.
An old PowerPoint file needs the installed conversion, or must first be saved
as a modern presentation or PDF.
Slide animations and live slideshow behaviour do not become board animations.
OpenBoard pages become locked pictures to write over.
Imports stop at 300 slides or pages.

**Check:** Editable PowerPoint fallback and OpenBoard import checked in app.
Conversion through installed Microsoft PowerPoint was not checked.

### Video / audio

**Find it:** More › Video / audio.

1. Choose a short clip.
2. Move and resize its tile.
3. Tap its play area, or select it and choose Play.
4. Use the player's controls; close it to stop.

The clip is stored inside the lesson file.
There is a 28 MB limit per clip to keep lesson saving manageable.
MP4 and WebM are the suggested video formats.
Audio choices include MP3, M4A, WAV, OGG and AAC; actual playback depends
on what the app can decode.
Turning a Notebook page stops the current clip.
PDF and picture exports show the tile or poster, not a playable clip.

**Check:** Clip insertion and playback controls checked in app.
Every codec and the speakers on a classroom panel were not checked.

### Capture something from another app

**Find it:** More › Capture.

1. Open the material you want in its own window.
2. Choose its window or a screen from Capture to lesson.
3. For a screen, use the whole picture or drag an area and adjust its corners.
4. Tap Use this area or Use whole screen.

The board briefly gets out of the way while taking the picture.
The result is a still, locked picture you can write over.
It is not a recording or a live link to the other app.
Refresh updates the list of available screens and windows.
Protected videos or windows can appear black; try capturing the screen.

**Check:** Capture workflow checked with test captures.
Real multi-monitor capture and protected-video behaviour were not checked.

1. Choose a subject tab.
2. Tap a tool; it is the same tool used elsewhere in the board.
3. Tap an active paper choice again to return to plain paper.

### Calculator

**Find it:** More › Calculator, or Subjects › Maths / Physics / Chemistry.

1. Tap the large keys to enter the sum.
2. Check the live answer, then tap equals.
3. Tap Write it on the board to keep that calculation as an editable object.
4. Drag the top grip to move the calculator; close it when finished.

Trigonometry uses **degrees**.
The last-key button removes a whole function key such as sine at once.
You must press equals before Write it on the board is available.
A sum with no finite answer shows Check the sum.
The floating calculator itself is not part of the saved page.

**Check:** Checked in app, including degrees and writing the result on the board.

### Equations and chemical equations

**Find it:** More › Equation, Subjects, or Ruler & compass › Equation….

1. Use the symbol buttons to start a fraction, root, power or other expression.
2. Change the letters and numbers in the entry box.
3. Check the drawn preview, then tap Insert.
4. Select the result and choose Edit to change it later.

The entry uses mathematical typesetting notation called LaTeX.
The chemistry and reaction buttons give starting forms for chemical formulae.
A valid preview is required before insertion.
The result has its own equation editor; it is not ordinary typed text.
Ctrl+Enter inserts or updates it.

**Check:** Equation and chemical-formula insertion checked in app.

### Graph a function

**Find it:** More › Graph, Subjects › Graph of a function,
or Ruler & compass › Graph of a function….

1. Choose a common curve, or enter a function with the large function keys.
2. Add other functions on the next lines if needed.
3. Set the x and y ranges and inspect the preview.
4. Tap Put on the board; select it and Edit to revise it later.

There can be up to five functions.
The largest bound must be greater than the smallest bound on each axis.
Multiplication can be implicit: 2x is accepted.
Sine and cosine on a graph use **radians**, unlike the calculator.
The graph's Zoom in, Zoom out and Reset buttons change its axis ranges;
they do not zoom the whole board.

**Check:** Function entry, multiple curves and saved graphs checked in app.

### Number lines and coordinate axes

**Find it:** More › Number line / Axes, or Subjects › Maths / Physics.

1. Pick a preset or set From, To, Step, and an optional name and unit.
2. For axes, choose Grid and Same scale both ways as needed.
3. Tap the preview to mark points; tap a mark again to remove it.
4. Turn on Show values / Show coordinates if you want labels.
5. Put it on the board. Select it and Edit to change its scale.

A fractional step displays fractional tick labels.
The step must be positive, and To must exceed From.
The app refuses an overcrowded scale: at most 200 step intervals per axis.
There can be up to 100 marked points.
Points snap to the scale, so they keep their values when the object moves.
Changing a range can drop points outside it when you apply the edit.
Same scale both ways gives one unit the same length horizontally and vertically.
These are measured drawing objects; drawing a freehand dot nearby does not
add a stored coordinate point.

**Check:** Number lines and axes checked in app.

### Periodic table

**Find it:** More › Periodic table, or Subjects › Chemistry.

1. Tap an element to enlarge it and see its facts.
2. Tap a family name to pick out that family; tap again to clear it.
3. Put this element on the board, or Put the whole table on the board.

The table contains 118 elements.
An element shows its number, symbol, name, family, atomic mass, period
and group where applicable.
The inserted result is a picture: reopen the periodic table for another choice.

**Check:** Checked in app.

## Draw with instruments

**Find them:** More › Ruler & compass, or Subjects › Maths.

Tap an instrument to bring it out; tap its choice again or its cross to remove it.
Several different instruments can be out together.
They float over the board and are **not saved with the lesson**.
Marks you draw with them are saved.
Their centimetres are screen drawing units, not a physical ruler calibration.

| Instrument | How to use it | Rule that is easy to miss |
| --- | --- | --- |
| Ruler | Drag its body into place. Turn its round arrow handle. Start a stroke on a long edge and draw along it. | The stroke must start on the edge to follow it. Starting inside the ruler moves the ruler. |
| Set square | Move its body and turn its handle. Start on an edge to draw a straight line. | It supplies 90° and 45° edges. Shift while rotating snaps to 15° steps. |
| Protractor | Place its centre and baseline on the angle. Drag the red measuring arm and read the angle. | It reads whole degrees from 0° to 180°. Only its straight baseline guides a straight stroke; its curved edge is not a circle-drawing tool. |
| Compass | Move the pin or leg to position it. Drag the top hinge sideways to change the radius. Sweep the pencil tip around the pin to draw an arc. | The pencil draws at the set radius; it does not set the radius. The permitted radius is about 0.5 to 30 drawing centimetres. |

Rotation also gently snaps near 15° steps.
The instrument's body, drawing edge, pencil and handles do different jobs;
if it moves when you expected a line, try starting exactly on the edge.

**Check:** All four instruments and their gestures checked in app with simulated input.
Physical centimetre calibration and panel stylus feel were not checked.

## Build an experiment from apparatus

### Open the cupboard and change a part

**Find it:** More › Apparatus, or Subjects › Physics / Chemistry / Biology.

1. Choose the subject tab.
2. Tap a part to take it out. The cupboard stays open for the next part.
3. Close the cupboard and use Select to move, resize or rotate parts.
4. Select one part and tap Set for its settings.
5. Tap or drag the live control on the part to use it.

There are **58 parts: 28 Physics, 17 Chemistry and 13 Biology**.
They are lesson objects and save with the board.
Locks stop their live controls, so unlock a part when a switch or knob will not move.
An apparatus part's Set panel can still change its parameters while locked.
Locking a part does not switch off a running circuit, flame or animation.
Live switches, knobs and terminals can respond while the drawing tool is in hand;
you do not need to draw a wire with the line tool.

Ready to use examples are Bulb and switch, Bulbs in series, Bulbs in parallel,
Ohm's law, Galvanometer, Charging a capacitor, Rays through a lens,
White light and a prism, Compass and magnet, Titration and Heating water.
Tap an example to add the whole arrangement to the current page.
It adds to existing work; it does not replace the lesson.

**Check:** Every part was opened in app and its offered settings and controls exercised.
Representative circuits, optics, titration, heating and biology actions were checked.
This is a classroom illustration, not validation of every scientific value.

### Wire electrical parts

**Find them:** Apparatus › Physics › Electricity.

1. Place a source, a switch and the parts you need.
2. Drag from one round terminal to another round terminal.
3. Release when the destination terminal is highlighted.
4. Complete the circuit and tap the switch.
5. Select a part and use Set to change its values.

Releasing away from a terminal creates no wire.
Wires follow the connected parts when you move them.
A red source terminal marks the positive side.
Join an ammeter in the current's path; connect a voltmeter across the part.
There is no separate wire cupboard tile: terminal-to-terminal dragging makes it.

| Part | What it does; how to use it; hidden rule |
| --- | --- |
| Cell | Supplies 1–2 V. Select › Set › Voltage, then wire both terminals into the circuit. |
| Battery | Supplies 1.5–24 V. Change Voltage in Set. A source current above 8 A produces a Short circuit! warning. |
| AC supply | Alternates the supply direction. Set Voltage and Slowed down to, from 0.2–2 Hz. This slow motion is for seeing changes, not a mains-frequency supply. |
| Switch | Tap its raised contact to open or close the circuit. |
| Resistor | Set Resistance, from 1–1000 ohms. Wire it into the current path. |

not a promise of the panel's advertised specification.
Use these can adjust stylus-size boundaries and enable palm erase
when the measurements distinguish them.
It does not repair a hardware driver or add missing touch points.

**Check:** Panel check opened in app.
A complete report from a physical classroom panel was not checked.

### Press and hold: the radial menu

**Find it:** Hold a pen, finger or mouse still on the board.
Enable it in Settings if it is off.

1. Hold until the circular menu appears.
2. Keep the contact down and slide to the tool, style or ink choice.
3. Lift to choose it.
4. Lift in the centre, outside the choices, or press Escape to cancel.

The middle ring offers the drawing tool, highlighter, eraser,
Select, Shapes, Text, Redo and Undo.
The outer top offers Pen, Pencil, Brush, Chalk and Felt marker styles.
The lower outer ring offers quick inks.
Choosing Shapes returns to the last shape tool.
There is no clear-board action in the ring.
Near an edge, the menu moves inward so all choices remain on screen;
slide deliberately before releasing there.
Dragging immediately starts the gesture instead of opening the menu.
Holding at the end of a drawn rough shape is a different action: shape snapping.

**Check:** Radial opening, choosing and cancelling checked with simulated input.
Comfort and accidental opening on a real panel were not checked.

## Optional Assistant

**Find it:** More › Assistant.

For help without an AI model:

1. Choose Planning board or Compare ideas for editable note layouts.
2. Or select objects first, then choose Arrange selection to lay them out in a grid.

For a connected model:

1. Open Connection settings and enter the details supplied for your model.
2. Choose the model, use Find models if appropriate, and save the settings.
3. Enter a request and tap Prepare draft.
4. Inspect the preview, then Apply draft or Discard.

A draft does not change the board until applied.
If the board has changed since the draft was made, prepare a fresh one.
One undo restores the board before an applied draft.
A local model must already be running on the PC.
An online service may need its own key and account.
The panel tells you whether your prompt and board text are going to a local
model or the entered online address.
There is no included model to download automatically from this panel.

To convert handwriting, select only the ordinary handwriting strokes,
choose To text or To maths, correct the proposed reading, then Replace the writing.
The selected writing's picture is sent to the configured model.
Accuracy, including Hindi, depends on that model.

External agents is a separate, optional connection for a technical helper.
Enable it for the session and give the copied connection configuration
to your own agent application.
It lets that agent read and edit the board directly.
Disabling closes the local connection and revokes its access token.
It requires Node.js 22 or later; ordinary teaching does not require this setup.

**Check:** Layout starters, drafts, stale-draft handling and handwriting workflow
checked against a local test service.
Real AI quality, online accounts and an owner's external-agent setup were not checked.

## Keep controls out of the way, or leave the board

| Tile or control | How to use it | Rule |
| --- | --- | --- |
| Hide toolbar | More › Hide toolbar, or Tab. Restore it with the small top-right button or Tab again. | Hiding controls does not delete work. |
| Full screen / In a window | More, or F11. | The menu label changes to the action you can take next. |
| Always on top | Use the pin in the window bar, or Ctrl+T. | Keeps the window above others; different from pass-through. |
| Minimise | More › Minimise, or the window-bar button. | Leaves the app running; reopen it from Windows. |
| Exit | More › Exit, or the window close button. | The app saves automatically. If it reports a failed save, resolve that before relying on the saved file. |
| Shortcuts | More › Shortcuts. | Opens the keyboard reference, including board, lesson, object and view controls. |

Drag the window bar to move a window; Alt+drag also moves it.
Use the window edges to resize it.
On a classroom panel, the edge menu tabs avoid reaching across the screen.
