# README artwork

The [cover](cover.png) combines the regenerated project logo and image-generated chemistry artwork
with editable HTML text in [cover.template.html](cover.template.html). It supersedes the earlier
projectile-themed `cover.svg`. It is a marketing illustration, not a screenshot or a claim of 3D
simulation. See [exact prompts, provenance and scientific references](GENERATION.md).

Run `npm run branding` to export the cover and [repo card](../social/README.md) from their templates.
The [brand directory](../brand/README.md) includes the true-alpha logo and production sizes.

The product screenshots, [six-image gallery](gallery/) and GIF come from synthetic example objects
and the real native lab renderer, using disposable profiles. No live board or personal desktop is
used. Gallery sources are the three studio frames in `docs/showcase-qa/` and the optics, waves and
circuits frames in `docs/science-qa/`; these are captures of implemented scenes, not generated art.

Reproduce after `npm run build`:

```powershell
New-Item -ItemType Directory -Force .work | Out-Null
$env:TEMP = (Resolve-Path .work).Path
$env:TMP = $env:TEMP
$env:FW_QA_ISOLATE = '1'
node e2e/readme-media.mjs
ffmpeg -y -framerate 10 -i .work/readme-frames/%04d.png -filter_complex "[0:v]split[a][b];[a]palettegen=stats_mode=diff[p];[b][p]paletteuse=dither=bayer:bayer_scale=3" -loop 0 docs/assets/readme/science-demo.gif
```

The GIF shows scripted playback through actual induction, chemistry and heart renderers. Timing is compressed for documentation. It does not claim free-form fluid simulation or diagnostic physiology. A static preview is available for readers who prefer less motion.
