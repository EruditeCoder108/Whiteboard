# Floating Whiteboard 1.5.0-beta.1 — Windows science preview

Release date: 2026-10-27. Target: **64-bit Windows 10/11 on Intel/AMD PCs**.

## Downloads

Use the [GitHub release](https://github.com/EruditeCoder108/Whiteboard/releases/tag/v1.5.0-beta.1):

- **Installer:** `Floating-Whiteboard-Setup-1.5.0-beta.1-x64.exe` — normal setup and shortcuts.
- **Portable:** `Floating-Whiteboard-Portable-1.5.0-beta.1-x64.exe` — run without installing;
  local data still lives in AppData rather than beside the EXE.
- **SHA256SUMS.txt:** compare downloaded files with their recorded SHA-256 hashes.
- **Source:** the tag's source archives contain the corresponding app code, lockfile, build scripts,
  GPLv3 licence and retained dependency notices. Build with `npm ci`, install Electron if scripts
  were skipped, then `npm run dist:preview`. Initial dependency installation needs the Internet.
- **Mediabunny source:** the exact upstream 1.61.3 source-bearing package is supplied separately
  for the MPL-2.0 media dependency, in addition to the retained notices and source links.

Normal drawing and science use needs no Node.js, Python, Blender, account, API key or Internet.

## Included

Fourteen native offline science experiments, including the deeper induction, colour chemistry and
heartbeat studios. Explore, play/pause/step/scrub, freeze and annotate, save/reopen and PNG export
are available on the same board as pressure-sensitive ink, editable objects and lesson replay.
The release also includes the new logo and GPL-3.0-only project licence with dependency notices.

## Preview boundaries

These files are **unsigned**. Windows trust controls or an organisation's policy may warn or block
them; do not disable protection. This is a prerelease, not a signed classroom-certified release.
Back up existing native board files before trying it. No installer was run on the owner's live
profile during QA, and acceptance on a second physical PC remains unverified.

Scientific scenes are 2D teaching models with stated approximations. Fluid/indicator behaviour and
heart physiology are illustrative. Continuous scientific motion is not captured in lesson timelines;
frozen edits and committed magnet traces are. See [scientific scope](../SCIENCE-SHOWCASE-QA.md).

## Validation

The source passed **211 unit tests**, TypeScript checking and a production build before packaging.
The packaged runtime passed **30 checks** in a disposable profile: all fourteen library entries,
magnet manipulation and undo/replay, chemistry/heart controls, deterministic seeking, annotations,
PNG decoding, compact-window access and exact save/reopen. No external renderer requests or uncaught
renderer errors were recorded. Packaged licence files and dependency notices match their sources.

Final binary sizes, signatures, hashes and packaged check results are recorded in the release's
validation attachment. The installer itself was not run, and these runtime checks do not establish
physical pen/touch or second-PC acceptance. Live profile data hashes were checked separately.
